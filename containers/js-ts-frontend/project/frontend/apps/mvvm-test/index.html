Меню профиля клиента

Компонент профиля с аватаром, адресом электронной почты и контекстными действиями.

Реализация: TypeScript-класс ClientProfileView отвечает за DOM, ClientProfileEzViewModel хранит состояние меню, а UserModel и MenuModel содержат данные пользователя и пунктов меню.

Привязка HTML-элемента

Изменение любого поля обновляет второе через общее ObserverProperty.
